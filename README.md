# 🏥 QueryCure
> Healthcare made simple, accessible, and fast.

QueryCure is a modern, responsive web application designed to bridge the gap between patients and specialized medical professionals through smart discovery, flexible booking, and an integrated digital pharmacy.

### 🛠️ Tech Stack
`HTML5` | `CSS3` | `JavaScript`

---

## ✨ Key Features

**For Doctors:**
* 📅 **Dashboard:** Manage upcoming schedules and patient queues.
* 💻 **Consultations:** Toggle availability for in-clinic or remote video visits.
* 🔗 **Auto-Links:** Automatically generate and distribute virtual meeting links.

**For Patients:**
* 🔍 **Smart Discovery:** Filter doctors by region, specialty, and expertise.
* ⏱️ **Flexible Booking:** Real-time slot booking for physical or virtual visits.
* 💊 **E-Pharmacy:** Integrated storefront for prescription and OTC medicines.

**Core System:**
* 🔐 Secure, role-based access control (Doctor/Patient).
* 📱 Mobile-first, soft-gradient UI with scroll-triggered animations.
